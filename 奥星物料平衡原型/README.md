# 奥星日物料平衡页面原型

单文件静态 HTML 原型,浏览器直接打开 `index.html` 即可。**页面内全部数量、罐号、人员均为演示数据**,用于讨论页面形态。

在线版本:https://claude.ai/artifact/W9A8bPgUvAoXjkQfUNWtBn

## 页面

| 页面 | 地址 | 主要使用角色 |
|---|---|---|
| 全厂日平衡总览 | `#overview` | 计划(首页)、财务 |
| 罐区库存与账实差异 | `#tanks` | 车间(首页) |
| 装置级平衡(二期) | `#units` | 车间、计划 |
| 异常与补采待办 | `#exceptions` | 车间、计划 |
| 数据确认与发布 | `#confirm` | 计划发布、财务月结锁定 |
| 日报输出 | `#report` | 财务(首页) |
| 主数据与取量规则 | `#config` | 系统管理员 / 口径负责人 |

## 全厂平衡式(厂界质量守恒,单位:吨)

原料 + 辅料及工艺水 − 产品 − 自用 − 排放 − 损失 − 罐存变化 = 平衡差

偏差率 = 平衡差 ÷ 原料油进厂量。生产日 0 点日结、±0.5% 关注线、±1.0% 补采线均为待与客户确认的假设。

依据:《奥星物料平衡模块规划》、《计量与日物料平衡落地方案》及本仓库茂名日效益资料。不涉及 MES。
